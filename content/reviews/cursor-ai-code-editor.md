## What is Cursor?

Cursor is an AI-first code editor built on VS Code, offering unprecedented AI-powered coding assistance. It integrates LLMs directly into your IDE for real-time code suggestions, refactoring, and explanation.

## Core Features

- **AI Autocomplete**: Context-aware code completion
- **Chat Interface**: Ask questions about your codebase
- **Cmd+K**: Quick AI actions inline
- **Multi-file Edits**: Changes across multiple files
- **Terminal Integration**: AI can run commands and fix errors

## Supported Languages

Python, JavaScript, TypeScript, Go, Rust, Java, C++, and 30+ more.
